## pdf
merge pdf | pdfunite *.pdf output.pdf
merge pdf2 | pdftk input1.pdf input2.pdf cat output output.pdf
divide pdf | pdftk input.pdf burst output page_%02d.pdf
exclude specified pages 1 | pdftk input.pdf cat '~5~7' output output.pdf # p5,p7を除外
extract specified pages 2 | pdftk input.pdf cat 1 4 6 output output.pdf # p1,p4,p6
extract specified pages 3 | pdftk input.pdf cat 4-6 output output.pdf # p4~p6
extract specified pages 4 | pdftk input.pdf cat 1 4-6 8 output output.pdf # p1,p4~p6,p8
reverse page order (end is last) | pdftk input.pdf cat end-1 output output.pdf
rotate 180 deg | down, south
rotate 90 deg | right, east
rotate 90 deg | left, west
rotate all pages 180 deg | pdftk input.pdf cat 1-enddown output output.pdf
rotate 3-5 pages 90 deg to right | pdftk input.pdf cat 1-2 3-5right 6-end output output.pdf
unlock pass | pdftk input.pdf input_pw RPOMPT output output.pdf
set pass | pdftk input.pdf output output.pdf user_pw PASSWORD

## scp
local to remote ローカルからリモート | scp </local/file> <username@domain:/remote/directory>
remote to local リモートからローカル | scp <username@domain:/remote/directory/file> </local/directory>
dir ディレクトリごとコピー | scp -r ...
key 鍵認証を用いてコピー | scp -i /path/to/key ...
port ポート番号指定してコピー | scp -P <port> ...
multiple files to remote 複数ファイルをリモートにコピー1 | scp <a.txt b.txt> <username@domain:/remote/directory>
multiple files to remote 複数ファイルをリモートにコピー2 | scp <{a,b,c}.txt> <username@domain:/remote/directory>
multiple files to remote 複数ファイルをリモートにコピー3 | scp <*.txt> <username@domain:/remote/directory>
multiple files to local 複数ファイルをローカルにコピー1 | scp <username@domain:/remote/directory/\{a.txt,b.jpg\}> </local/directory>
multiple files to local 複数ファイルをローカルにコピー2 | scp <username@domain:/remote/directory/\{a,b,c}.txt\}> </local/directory>
multiple files to local 複数ファイルをローカルにコピー3 | scp <username@domain:/remote/directory/*.txt\}> </local/directory>

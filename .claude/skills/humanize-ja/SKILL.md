# humanize-ja — LLM日本語を人の文章に直す

書いた文章を提出・投影する前に必ずこのリストを通す。1項目でも引っかかったら直す。
「文字を減らす」のではなく「LLMの癖を消す」のが目的。

## 1. 兆候チェックリスト（見つけたら直す）

### 語彙・言い回し
- [ ] **気取った比喩・借り物の語**: 「処方箋」「羅針盤」「試金石」「一丁目一番地」。実務の場で人は言わない
- [ ] **抽象美文**: 貢献する/実現する/向上させる だけで数字がない文
- [ ] **曖昧語**: 適切に・様々な・等・最適化・大幅に・しっかり
- [ ] **カタカナ語の連発**: ソリューション、シナジー、アジリティ。日本語で言えるものは日本語で
- [ ] **同語反復**: 同じ名詞・同じ述語が3文以内に再登場する

### 構文・リズム
- [ ] **体言止めの3連発**: 「取り込みは確定的に、AIは補完だけに、確認は来歴に」型。標語っぽさはLLMの署名。1つは動詞で終える
- [ ] **「AはBに、CはDに」の対句乱発**: 1ページに1回まで
- [ ] **ダッシュ（—）・コロンでの言い換え連発**: 「X — つまりY」を多用しない。読点と文で繋ぐ
- [ ] **接続詞の頭出し**: これにより/さらに/また/一方で が段落頭に並ぶ
- [ ] **文長が均一**: 全部の文が40字前後で揃っている。短い文を混ぜる
- [ ] **文末が単調**: 「〜する。〜する。〜する。」。〜だ/〜ではない/体言/疑問を混ぜる
- [ ] **「〜という」の多用**、「〜することができる」（→「〜できる」）

### 体裁
- [ ] **太字の乱用**: 段落の中のキーワードを機械的に太字にする。1ページに何箇所も
      太字があると、どれも強調にならない。太字は1セクション1箇所まで
- [ ] **見出し+箇条書きの入れ子が均一**: どの見出しにも3〜4個の箇条書きがぶら下がる。
      散文で書ける部分は散文に戻す

### 内容
- [ ] **文末の尾ひれ**: 「〜を示している」「〜を浮き彫りにする」「〜を意味する」を
      文末に足して深みを装う型 (英語の ", highlighting ~" の日本語版)。
      文ごと削るか、主張なら独立した文にする
- [ ] **述語のごまかし**: 「〜だ」でいい場面の「〜となっている」「〜を担っている」
      「〜という位置づけだ」。断定を避けているだけなら戻す
- [ ] **当事者性の欠如**: 誰の経験かわからない一般論。一人称の事実を1〜2文入れる
- [ ] **曖昧引用**: 「ある調査によると」。調査名・年・nを書く
- [ ] **数字も固有名詞もない文**: (a)数字を足す (b)固有名詞を足す (c)削る、のどれかにする
- [ ] **文脈の飛び**: 前の文と次の文の間で読者が推論を要求される

## 2. 書き換えの手筋

| LLMの癖 | 直し方 | 例 |
|---|---|---|
| 気取った語 | 実務の言葉に | 処方箋のMBSE → 解決策とされてきたMBSE |
| 標語型体言止め | 主語と動詞の文に | 確認は来歴に → 人が確認した事実を記録として残す |
| 名詞の塊 | 動詞でほどく | 導入負荷の低減を実現 → 導入の手間を減らす |
| 抽象 | 具体の1例で置換 | 様々なツール → ExcelとSlack |
| 対句 | 片方を崩す | AはXに、BはYに → Aは Xする。Bは Yに回る |

## 3. 自己監査プロンプト（最終パス）

> 次の文章を「読み手の専門家」と「AI文章検出の専門家」の二役で点検せよ。
> 1) 読み手: 数値・固有名詞・出典のない主張、論理の飛びを列挙
> 2) AI検出: 上のチェックリストの兆候を具体箇所つきで列挙
> 3) 修正案を提示。新しい事実・数値は創作せず、不足は【要確認】と書く

最後は必ず人が音読する。声に出して詰まる文はLLMの文。

## 4. 例外

- 図中のラベル・表の見出しは体言止めでよい（図は文章ではない）
- 見出し（スライドタイトル）は主張文にするが、簡潔さ優先で「〜する」止めは可
- 法令・公募要領の引用は原文のまま
